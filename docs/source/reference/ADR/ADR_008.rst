=======================================
ADR-008: RDBモデルを使用しなかった理由
=======================================

**Status**: **`Accepted`**

📋 Context
-----------
Ledgerへのread/writeモデルとして、（MVCで言うModelのような）を使うことも考えられました。

しかし、このread/writeをMVC的なモデルに担わせる実装を試みたところ、同じモデルの継時的な変化の扱いや、読み取りの対象が「最新の状態」とは限らないといった点で概念的な整理の難しさが生じました。

💡 Decision
------------
RDBモデル（MVC的なモデル）を使用せず、CQRSでいう「さまざまなprojectionを作る」という読み取りモデルを採用することとしました。

この移行により、上述の概念的な整理の難しさが解消されました。

✨ Consequences
-----------------
**Positive:**
* 継時的な変化の扱いや、読み取り対象の状態（最新かどうか）に関する概念的な整理が容易になった。

**Negative:**
* (特になし)
